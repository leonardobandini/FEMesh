Gmsh 2D meshing inside SAP2000 shells

Select areas, joints and frames in SAP2000. Gmsh generates triangles, quadrangles or a mixed mesh; preview, apply or undo the result. V2 uses the SAP2000 xAPI to transfer the mesh and exposes Gmsh algorithms and their parameters.

Historical archive: these 24 Classic trials and screenshots document the old SAP2000 host. They are not images of the current FEMesh interface or CSiBridge tests. For the current version of FEMesh on SAP2000/CSiBridge, use the updated guide with six current English/Italian interface captures.

A controlled first mesh

  1. Open a saved model and select at least one planar shell area. Explicitly select point objects that must become mesh vertices and frame objects that the mesh should follow. Links are counted but are not meshing constraints.
  2. Start SAP2000 Gmsh Mesh from Tools. The selection summary lists the areas, frames and joints. Start with a single area to learn an algorithm; for adjacent areas V2 builds one Gmsh model with shared boundary curves.
  3. In Algorithms choose Default options or set algorithm, target size, recombination, smoothing and optimization. In Gmsh options tick a tree entry to activate your override and edit its value. Unchecked entries keep Gmsh's own defaults.
  4. Click Generate, inspect the viewport, element totals and Mesh quality. Confirm with Apply or go back with Undo mesh. The SDB is not automatically saved.

V2 updates: the plugin checks a V2-only manifest when opened. If a new version is available, click Download in the footer to open its ZIP in your browser. Extract the ZIP, close SAP2000, run install_plugin.cmd, then restart SAP2000. V1 uses a separate update feed; V2 does not install updates automatically.

Press F1 or the ? in the plugin title bar. The selected UI language opens the corresponding local help page. No Internet connection is needed.

2D algorithms: what they do

Mesh.Algorithm selects Gmsh's unstructured surface generator. It does not automatically choose local sizing, quad recombination or a block decomposition. The plugin does not silently replace an algorithm on error. Explicitly enabling Mesh.AlgorithmSwitchOnFailure permits Gmsh's own fallback for some 2D methods.

CodeAlgorithmUse and limitations
1MeshAdaptLocally modifies triangles using edge swaps, splits and collapses. It can handle complex shapes; still check frame and size constraints.
2AutomaticUses Delaunay for plane surfaces and MeshAdapt for others. This is an internal Gmsh choice, not a plugin quality search over multiple candidates.
3Initial mesh onlyBuilds only the initial triangulation. It does not enforce the requested target size. Use it to diagnose geometry, not as a falsely low-count final solution.
5DelaunayInserts points to build triangles. Often fast on large plane surfaces and suitable for strong size-field variation.
6Frontal-DelaunayGrows triangles from advancing fronts; a useful quality-oriented baseline before recombination.
7BAMGSupports anisotropic triangulation. On some polygons it may fail to follow selected frames; the backend verifies every frame before importing into SAP.
8Frontal-Delaunay for QuadsBuilds triangles that recombine well. 8 + Simple (0) may leave more triangles but fewer elements; 8 + Blossom (1) may increase quads and split boundary segments.
11Quasi-structured QuadUses a direction field to organize quad-dominant meshes; on some polygons or seams it can become extremely dense or incompatible.

3D algorithms, tetrahedra and hexahedra require solid geometry and a SolidObj importer. They are not alternative 2D shell algorithms.

Element sizes and the option tree

Maximum size sets Mesh.MeshSizeMax in current SAP2000 units; suffixes such as 0.55m or 25mm are accepted. This is a Gmsh target size, not a guarantee about final edge lengths. Minimum (% of maximum) is editable (default 80%): maximum 0.55 m gives minimum 0.44 m, or 0.6 m gives 0.48 m. Editing the maximum or percentage updates the minimum. Default options resets the percentage to 80% without touching your typed maximum.

OptionGmsh default / purpose
Mesh.MeshSizeMinGmsh default 0. When active in V2, this value is maximum size × the percentage from Algorithms (initially 80%). The numeric tree cell displays the computed value rather than being a second independent input. It is not a minimum real edge length; untick it to use Gmsh's default 0.
Mesh.MeshSizeFactor1. Scales target sizes. A factor below 1 refines the mesh even when MeshSizeMax stays fixed.
Mesh.MeshSizeFromPoints1. Use sizes attached to geometry points. Set to 0 to disable their sizing effect: explicitly selected SAP joints still have to become mesh vertices.
Mesh.MeshSizeExtendFromBoundary1. Propagate boundary sizing into surfaces; 0 disables it. More specialized Gmsh values are available in the numeric control.
Mesh.MeshSizeFromCurvature0. Target elements per turn of CAD curvature. Polygonal SAP circle segments are not analytic CAD arcs.
Mesh.AlgorithmSwitchOnFailureGmsh default 1. The plugin Default preset explicitly uses 0, so an explicit algorithm trial does not silently change to MeshAdapt.
Mesh.RecombineOptimizeTopology5. Passes for improving recombined quad topology and removing diamond patterns.
Mesh.RecombineNodeRepositioning1. Enable (1) or disable (0) moving nodes while recombining.
Mesh.RecombineMinimumQuality0.01. Minimum acceptable recombined-quad quality; higher values may leave more triangles.
Mesh.SubdivisionAlgorithm0 none; 1 split into quads; 2 hexahedra (3D, rejected for shells); 3 barycentric. May insert boundary joints.
Mesh.QuadqsSizemapMethod3. Size-map method (0–4) for algorithm 11, Quasi-structured Quad.
Mesh.QuadqsScalingOnTriangulation0.75. Background triangulation-to-quadrangulation edge-length ratio for algorithm 11.

Tick an entry to enable its override and enter a typed value to the right. In Advanced, enter other numeric options as Mesh.Name = value, one per line with dot decimals; # starts a comment. Duplicating a tree entry is an error. The actual JSON sent to Gmsh is shown underneath.

The “Default options” command

Restores algorithm 8, Simple 0 recombination, smoothing 1, size factor 1, subdivision 0, order 1 and the 80% minimum percentage. The quality-assessment tolerance is fixed at 20% and has no visible control. It keeps the maximum you entered and recalculates its minimum: 0.55 m → 0.44 m (440 mm), 0.6 m → 0.48 m. Paolo's historical screenshot instead showed 0.45 m minimum and 0.55 m maximum; it is different from the new Default. The plugin sets Mesh.AlgorithmSwitchOnFailure=0 for reproducible comparisons; the screenshot does not show that option or the commands in Cerchio02.geo.

Quads, smoothing and optimization

Tick Recombine triangles to set Mesh.RecombineAll=1. 0 Simple performs local pairing; 1 Blossom tries a broader matching. 2 Simple full-quad and 3 Blossom full-quad seek all-quad meshes but can fail when a prescribed boundary cannot be divided as required or create many extra elements. Never force all-quads at the expense of angles or boundary constraints.

Smoothing steps is Gmsh's Mesh.Smoothing (0–100). Optimize 2D offers Laplace2D, Relocate2D and QuadQuasiStructured with 1–100 iterations. The last needs quads: enable recombination or use a quad-generating algorithm. The current SAP adapter imports only first-order 3/4-node triangles and quadrangles. High-order or 3D optimization is not a 2D-shell choice; Mesh.SubdivisionAlgorithm=2 (all hexes) is rejected.

Structured tab: transfinite meshes

Unstructured uses the chosen 2D generator. Automatic transfinite asks Gmsh to recognize suitable quadrangular faces: compatible faces are constrained while others may remain unstructured. Enter the maximum corner angle in degrees (Default: 135°).

Manual transfinite assigns a node count per curve plus Progression (geometric progression), Bump (refinement at both ends) or Beta (beta-law distribution), with a positive coefficient. For non-recombined triangular faces choose Left, Right, AlternateLeft or AlternateRight. Each patch must have 3 or 4 boundary curves. A many-sided annular slab needs appropriate patches first; changing one meshing-algorithm number cannot make a 20-edge face into a structured four-sided block. Adjacent patches must share the same stations along their common sides.

Local refinement with Gmsh size fields

The Fields tab creates Distance + Threshold around selected frame curves, explicitly selected joints, or both. Set Near size, Far size, Near distance and Far distance in SAP units. At distances below Near distance the target is Near size, above Far distance it is Far size, and in between Gmsh interpolates. The global maximum still applies.

Important dependency: maximum 0.55 m with an 80% minimum sets Mesh.MeshSizeMin=0.44. Near size 0.25 m would be clamped to 0.44 m. Lower the minimum percentage (e.g. 40%) or untick MeshSizeMin: V2 reports the conflict before meshing. If point/boundary sizing dominates your field, try Mesh.MeshSizeFromPoints=0 and Mesh.MeshSizeExtendFromBoundary=0; selected geometric constraints remain.

Other documented size-field types

Other Gmsh fields… takes a JSON array with id, type, options and background. The Gmsh 4.15.2 adapter supports the 29 documented field types through numeric, string and list parameters. Reference earlier fields by id; $selectedFrames in CurvesList and $selectedJoints in PointsList resolve to the model's actual Gmsh entity tags. Lengths are in current SAP units. Use a single background field and do not enable the simplified Distance+Threshold box at the same time.

[{"id":"guide","type":"Distance","options":{"CurvesList":"$selectedFrames"}},
 {"type":"Threshold","options":{"InField":"guide","SizeMin":0.25,
   "SizeMax":0.55,"DistMin":0,"DistMax":1},"background":true}]

The sample numbers are in metres only if SAP uses metres. Other field types include Box, Ball, MathEval, Min, Max and BoundaryLayer; the options and applicability depend on the field type.

Circular holes and structured O-grids

Select the shells to mesh. In Holes enable the circular cut, choose a SAP2000 point-object group containing hole centres, and enter a diameter in current SAP length units. The V2 cuts holes before meshing, including circles spanning shared area seams. Original centre joints may remain unconnected inside the void.

Structured O-grid around circular holes creates radial quadrilateral sectors with conforming shared seams. It requires an enabled circular cut and a selected centre group. Triangles can still occur outside the ring. The ring needs clearance from selected joints, frames, other holes and the boundary; incompatible seams or constraints cause an explicit error. With O-grid unchecked, the standard circular cut does not produce a structured ring. All first-order circle boundaries are approximated by straight edges. Inspect the void, ring and quality report.

Openings from grouped frames and shell edges

In the Holes tab enable Cut openings bounded by grouped frames or shell edges and choose the SAP2000 group containing the boundary frames or the incident shells whose edges bound the opening. Select all shell areas to mesh, including incident areas when using their edges. V2 splits frames at intersections, finds closed planar cells, joins fragments across unprotected shared seams and removes only cells whose entire perimeter is eligible. An open chain or a closed chain outside the selected group stays filled and still constrains mesh edges. If the selected group creates no enclosed cell, generation stops with an explicit error.

Tests cover a single shell, four adjoining shells, intersecting frames, three frames plus an incident shell edge, and five shells whose opening uses shell edges alone. The original SAP2000 frame objects are not physically split; their geometry must be reproduced by continuous shell-edge chains. Inspect quality and seam conformity for each result.

Exact symmetry

In the SAP2000 tab tick Enforce exact symmetry and choose a reflection axis detected from the selected geometry and constraints, or two perpendicular axes if available. Shell topology is mirrored from a half or quadrant and validated before import. Hole centres must lie on the axis or form reflected pairs. Several selected areas may be mirrored or meshed with conforming seams. This setting does not turn an asymmetric source geometry into a symmetric one: incompatible geometry or constraints are rejected.

Preview, quality and SAP2000 model

SAP2000 previews generated shells; a local CSV snapshot supports restoration. FAST transfers the generated joints and shell geometry in bulk through the SAP2000 editable-tables API. With FAST off, Standard transfers individual objects via SAP2000 API calls. These are two ways to transfer the same Gmsh mesh into SAP2000; they do not select a different meshing algorithm. A numbered backup copies the last saved SDB before Generate. Apply removes originals from the in-memory model; Undo mesh restores them while the dialog remains open.

The initial quality tolerance is 20% of the requested maximum: it changes the assessment, not Mesh.MeshSizeMax sent to Gmsh. Shape quality is the mean of individual element scores weighted by physical element area. Dimension exceptions can cover at most 1% of total area, while a free-edge/nominal-size ratio prevents gross outliers; inverted or degenerate elements always fail. The factor 1.172 is a disclosed project criterion, not a standard ascribed to Gmsh or the literature.

A pre-existing 1.172 m edge at the Circular_Floor square opening is a geometric length, separate from the factor 1.172: at 0.5 m it has ratio 2.344. It is separately recorded only for that protected original interval and cannot loosen the whole domain. The unchecked-by-default “No added nodes on edges with selected interior joints” option protects those original stations and checks the result before SAP2000 import. A very long locked edge can still force long interior transition edges; inspect the report rather than relying on element count alone.

How intermediate joints are calculated. Source-joint values remain unchanged. Edges are linear; the interior of a four-joint shell uses inverse bilinear natural coordinates. For polygons with more than four joints, joint patterns use an affine-preserving thin-plate interpolant clamped to the source minimum/maximum, while thickness and explicit joint offsets use nonnegative mean-value coordinates. Type 1 joint offsets retain their pattern name and scale after the pattern has been propagated to generated joints. Every assignment is read back through the API and an error triggers rollback. These are validated geometric approximations, not an exact reproduction of SAP2000's undocumented internal algorithm: local differences can remain even when total volume and global average are close.

Recommended downstream check: when joint patterns, thickness overwrites or joint offsets are important to design, inspect and preferably reassign them directly in SAP2000 after the plugin has meshed the model. Apply the same rule to design overwrites and every yellow or red property. The backup contains the last saved SDB, not unsaved changes; Undo cannot guarantee data that SAP does not expose through its API.

If a method produces no mesh

  • At least one shell must be selected and the SAP model must be unlocked. A constraining frame must lie in the selected area plane.
  • A selected algorithm can fail on a particular topology: full-quad may report that a 1D boundary mesh cannot be divided by two. Algorithm 9 can terminate the native worker for some inputs; the V2 keeps this separate from the SAP model.
  • Manual transfinite needs 3/4-sided patches; building those patches is a geometrical step, not another algorithm code.
  • Higher-order shells, 3D solid meshing and physically splitting SAP frame objects are not implemented. A group without an eligible closed cell does not produce an opening; circular holes need a point group and a diameter.
  • Unreadable global analysis tables do not change with the mesh. An unreadable design overwrite/procedure table raises the warning described above. Geometry, loads, springs and other essential assignments still require a readable snapshot.
