# SAP2000 Quad Mesher V2 2.0.52

SAP2000 27.1 può restituire **zero record** da `GetTableForEditingArray("Area Design Procedures")` subito dopo l'uso di **Display → Show Tables → Connectivity Data → Joint Coordinates**, anche se `GetTableForDisplayArray` mostra ancora le procedure originali. La 2.0.52 confronta i getter: acquisisce le procedure dal getter di visualizzazione quando l'editabile le omette e le conserva nello snapshot di Annulla. Non interpreta zero righe editabili come `No Design` senza una verifica.

Se, dopo l'import, SAP lascia realmente le nuove shell in **`No Design`** invece di **`Concrete Shell Design`**, il plugin ammette l'anteprima soltanto quando l'inventario delle aree e le assegnazioni delle sezioni risultano coerenti. **Applica richiede un consenso esplicito non disattivabile**: la procedura di progetto sulle nuove shell andrà reimpostata, così come eventuali sovrascritture Concrete Shell Design. **Annulla mesh** ripristina le procedure originarie tramite lo snapshot CSV. Il backup numerato contiene solo l'ultimo SDB salvato; il plugin non salva automaticamente il modello.

Sul modello `Concrete_Barrier(0.3m).sdb` la sequenza GUI con Show Tables, riapertura dell'originale senza salvataggio e nuova generazione è stata verificata manualmente dall'utente. Gli SDB originali restano invariati. La suite atomica SAP2000 27.1 ha **36/36 PASS**: quattro sessioni avviate in parallelo, 27 casi passati nei gruppi 2–4 e 9 nel gruppo 1 ripetuto su una nuova sessione dopo un timeout di SAP nell'apertura di `nTEST005` (prima dell'ingresso nel plugin). Anche Anteprima→Annulla Standard (`nTEST004`) e FAST (`nTEST028`) passano. Dettagli: `reports/CONCRETE_BARRIER_2026-10-19.md`.
