# SAP2000 Quad Mesher V2 2.0.43 — chiusura anteprima con scelta obbligata

Quando esiste una mesh in anteprima e l'utente chiude la finestra delle opzioni con la **X**, il plugin chiede obbligatoriamente se **Annulla mesh** o **Applica mesh**. Non esiste un terzo comando di chiusura della richiesta. La finestra di stato comunica il ripristino dello snapshot oppure l'applicazione e resta visibile finché l'operazione non termina; soltanto allora il plugin si chiude. Se non si è ancora generata una mesh, o se questa è già stata applicata, la X chiude normalmente. La scelta non salva automaticamente il modello SDB.

La scheda **Gmsh JSON** di debug non compare più: l'interfaccia ha tre schede. Gli override numerici precedentemente memorizzati sotto la scheda rimossa non modificano silenziosamente le mesh future; il JSON effettivo rimane disponibile nella diagnostica. Non viene introdotta alcuna opzione per gli appunti.

Le diciture inglesi e la disposizione delle schede **Additional options** e **Transfer options** seguono i riferimenti forniti dall'utente. L'asse di simmetria ha un'etichetta propria e lo stesso allineamento/larghezza dei menu Gruppo; i testi descrittivi prima riquadrati in blu sono rimossi. La scheda Gmsh mantiene il controllo dei passaggi di smoothing della 2.0.42 e la pipeline Simple/Blossom coerente.

Verifiche: build senza avvisi; guida e layout EN/IT verificati; prova della finestra di conferma con soli due pulsanti, inclusa la X della conferma che non consente di uscire. Su copie SAP isolate di `nTEST001`, **X → Annulla mesh** ripristina lo snapshot e il singolo shell iniziale senza modificare il file sorgente, mentre **X → Applica mesh** mantiene i 50 quad. Il caso multi-area `nTEST008` è PASS sullo ZIP 2.0.43 (276 shell, con frame selezionati). Test backend Gmsh (24 PASS, 1 skipped), ZIP standalone, migrazione del menu, feed locale e checksum SHA-256 PASS. La matrice SAP 36/36 era stata completata sulla 2.0.42: in questa release di interfaccia/chiusura sono stati ripetuti i casi mirati, non l'intera matrice.
